Razredi — kratek pregled

Na izpitu redko, zato samo osnovni zapis.

Osnovni vzorec razreda

class Predmet:
    def __init__(self, masa, starost):
        self.masa = masa
        self.starost = starost

    def __str__(self):
        return f"Predmet z maso {self.masa}."

    def __repr__(self):
        return f"Predmet({self.masa}, {self.starost})"

    def __lt__(self, drugi):
        return (self.masa, self.starost) < (drugi.masa, drugi.starost)
  • self je trenutni objekt.
  • __init__ nastavi atribute.
  • __str__ uporablja print(objekt).
  • __repr__ je predstavitev objekta v konzoli.
